# Pixel Art

A pixel art editor for mytekDev, based on [Piskel](https://github.com/piskelapp/piskel).

**Try it in your browser, no account needed:** [mytekdev.com/tools/pixel-art](https://mytekdev.com/tools/pixel-art). The page has a live demo and explains what students learn from it.
